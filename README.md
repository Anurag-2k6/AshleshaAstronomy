# 🌌 Space Elevator — Ashlesha Astronomy Club Recruitment 2026–27

An interactive space-themed website that takes the visitor from the microscopic world to the observable Universe.

## Features

### Core requirements
- 7 cosmic scale levels: Micro World → Human Scale → Earth → Solar System → Milky Way → Local Group → Observable Universe
- Level name, visual and two facts for every level
- Previous/Next navigation
- Clickable level rail and level cards
- Smooth transitions and animations
- Responsive HTML/CSS/JavaScript implementation
- Space-themed UI, typography, gradients and animated background

### Bonus features included
- Clickable cosmic objects / level cards
- Scale/progress animation
- Mini 3-question astronomy quiz
- Two additional levels beyond the required five
- Small optional sound effect
- Keyboard navigation with arrow keys
- Restart journey button

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Inter + Orbitron

## Run locally

No build system or installation is required.

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Click **Begin the Journey**.
4. Use the buttons, cards, rail markers or keyboard arrow keys to navigate.

For a local server, you can also run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The project is static, so it can be deployed using GitHub Pages, Netlify, Vercel, or any static hosting service.

### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. Open **Settings → Pages**.
4. Select the main branch and root folder.
5. Save and use the generated Pages URL as the working website link.
